# assets/

Images, diagrams and screenshots referenced by this part's `README.md`.

**Conventions**

- Lowercase, hyphenated filenames: `agent-config-panel.png`, `concept-diagram.png`.
- Prefix with a step number when order matters: `01-create-tool.png`.
- PNG for screenshots, SVG for diagrams where possible (crisper, diffable).
- Keep images under ~500 KB; crop to the relevant UI rather than shipping full-screen captures.
- Redact API keys, tokens, account emails and customer data before committing.
- Reference from the article with a relative path: `![Alt text](./assets/01-create-tool.png)`.
